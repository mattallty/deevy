# AGPL-3.0 as the license

deevy is open source from day one and built first for its authors' own team, but a hosted offering is a real
option later. AGPL-3.0 keeps that door open: anyone can self-host, fork, and modify, but offering a modified deevy
as a network service requires publishing the changes. The cost is that some enterprises ban AGPL and that a later
relicensing needs every contributor's consent.

## Considered options

- **Apache-2.0 / MIT.** Maximal adoption; permits closed hosted forks, so a future hosted offering could only
  compete on operations.
- **Source-available (BSL, FSL).** Rejected: not open source, and the project's premise is that agent-native
  tooling should be open.
